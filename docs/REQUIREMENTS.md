## 1. 项目背景与目标

### 1.1 背景

原始素材作者基于九年实盘经验，指出散户亏损的核心原因：**盲目追高、频繁打板、乱做连板妖股**。原文称其本金曾在半年内腰斩，后放弃全部花哨战法与高频打板，用两年时间复盘上千只强势股走势，总结出一套自述「最稳、最适合散户、容错率最高」的短线体系——**涨停回调低吸战法**，并称九年间只坚持这一种模式，将 15 万本金做到 230 万。

该战法的核心洞察是一句反直觉的判断：

> **「涨停是主力的出货舞台，回调才是散户的低吸机会。」**
> 追高是接盘博弈，回调是顺势低吸。

### 1.2 项目目标

将上述**经验型、口语化、散落于多张图文**的交易方法，转化为**可执行、可复现、可验证、可视化**的量化选股与分析平台。

具体目标：

| 编号 | 目标 | 衡量标准 |
|---|---|---|
| G1 | **规则可计算化** | 原文中「放量实体」「低位首板」「持续缩量」「守住支撑」等定性描述，全部落地为明确的数值判据 |
| G2 | **选股自动化** | 每日可一键扫描股票池，输出符合战法的候选标的及评分排序 |
| G3 | **决策可视化** | 五大信号的通过情况、支撑位、买卖计划、风险点全部图形化呈现 |
| G4 | **纪律可执行** | 交易纪律（空仓、分批、止损）内嵌为系统输出，而非仅靠人记忆 |
| G5 | **可验证性** | 提供历史回测，统计信号样本的胜率、盈亏比、最大回撤，避免「只讲不验」 |
| G6 | **可交付部署** | 一键部署脚本 + 容器化，可在云服务器 5 分钟内上线 |

### 1.3 产品定位

- **性质**：技术研究与学习工具（research / educational tool），**不是**投资顾问服务。
- **使用者**：具备基础 A 股交易常识、希望以纪律化方式参与强势股回调机会的个人投资者。
- **不做什么**：不提供自动下单、不接入券商交易接口、不承诺收益、不构成投资建议。

## 3. 战法理论体系（业务规则）

### 3.1 体系全貌

```
                    ┌─────────────────────────────┐
                    │  第 0 层：理念与反面对照       │
                    │  不追涨停、不做连板、不打板    │
                    │  只做「优质首板 → 回调低吸」   │
                    └──────────────┬──────────────┘
                                   ▼
                    ┌─────────────────────────────┐
                    │  第 1 层：优质首板筛选（门槛） │
                    │  三条硬标准 + 四类一票否决     │
                    │  不合格 → 直接出局，不看回调   │
                    └──────────────┬──────────────┘
                                   ▼
                    ┌─────────────────────────────┐
                    │  第 2 层：回调观察            │
                    │  等待回调 3~15 日             │
                    │  跟踪量能 / 支撑 / 形态        │
                    └──────────────┬──────────────┘
                                   ▼
                    ┌─────────────────────────────┐
                    │  第 3 层：五大共振信号（入场） │
                    │  五信号全通过 = 可低吸         │
                    │  缺一不买                    │
                    └──────────────┬──────────────┘
                                   ▼
                    ┌─────────────────────────────┐
                    │  第 4 层：买卖与风控          │
                    │  分批低吸 / 止损位 / 两档止盈  │
                    └──────────────┬──────────────┘
                                   ▼
                    ┌─────────────────────────────┐
                    │  第 5 层：交易纪律（不可违背） │
                    │  无信号空仓 / 破位止损 / 分批  │
                    └─────────────────────────────┘
```

### 3.2 第 0 层：理念（反面对照表）

| 追高打板（原文明确否定） | 涨停回调低吸（原文主张） |
|---|---|
| 涨停 = 强势，追进去就能赚钱 | 涨停 = 主力出货舞台 |
| 拼手速、拼情绪、拼运气 | 赚洗盘结束、二次拉升的确定性利润 |
| 情绪退潮 → 次日大幅低开、直接闷杀 | 回调企稳 → 二波主升 |
| 接盘博弈 | 顺势低吸 |
| 追涨 → 被套、炸板、闷杀 | 低吸 → 容错高、胜率稳 |
| 结论：**放弃** | 结论：**只做这一种模式** |

### 3.3 第 1 层：优质首板的三条硬标准

原文明确「**我只参与符合三个标准的优质首板涨停，这是整套战法的根基**」，且「涨停质量，直接决定回调后的上涨概率」。

| 编号 | 标准（原文） | 原文理由 | 工程化判据 |
|---|---|---|---|
| S1 | **只做低位首板，不做连板妖股** | 连板高位票：资金分歧大、兑现压力重、情绪波动极强，回调大多是见顶回落；低位首板：主力第一次正式进场拉升，蓄力充分、筹码干净、没有大量获利盘，回调洗盘后重启概率最高 | ① 前 1、2 个交易日均无涨停（排除连板）；② 涨停日收盘价在近 120 日区间的位置比例 `(close − low120) / (high120 − low120) ≤ 0.80`（排除高位） |
| S2 | **只做放量实体涨停，拒绝缩量一字板** | 真正的强势启动一定是放量换手涨停；充分换手代表多空博弈积极、资金接力充足、主力真实扫货。一字缩量/无量涨停没有经过换手，筹码极不稳定，一旦开板就是剧烈分歧，回调没有参与价值 | ① `量比 = 当日量 / 前5日均量 ≥ 1.2`（放量）；② 换手率 `≥ 3%`（有换手）；③ 非一字板（`open ≠ high` 或 `open ≠ close`） |
| S3 | **只做日内扎实涨停，拒绝尾盘偷袭板** | 只保留早盘、午盘稳步拉升封死的实体板；全天弱势、尾盘最后几分钟偷袭拉升的「强行做板」没有持续性 | 日线数据无法直接获得封板时刻，采用**代理判据**：排除 `close == high` 且 `(close − open) / pre_close ≥ 6%` 且换手率 `< 3%` 的疑似尾盘偷袭形态 |

### 3.4 第 1 层：四类一票否决的涨停

原文：「**烂板、偷袭板、缩量板、高位板，回调大概率是下跌中继，坚决不能碰**」；另加「K 线的涨停，都是主力诱多做图形，目的就是第二天高开出货，这类票直接拉黑，不看回调」。

| 类型 | 代码枚举 | 判定条件 | 原文性质 |
|---|---|---|---|
| 烂板 / 炸板 | `WEAK_SEAL` | `close < high` 且 `(high − close) / pre_close ≥ 3%` | 封板失败，抛压沉重 |
| 尾盘偷袭板 | `TAIL_SNEAK` | `close == high` 且 `(close − open) / pre_close ≥ 6%` 且换手 `turnover < 3%` | 主力做图诱多，次日高开出货 |
| 缩量一字板 | `ONE_WORD` | `open == high == close`，或开盘涨幅 `≥ 9.5%`，或 `volRatio < 1.2` | 未经换手，筹码极不稳定 |
| 高位板 | `HIGH_POSITION` | 涨停日位置比例 `> 0.80` | 兑现压力重，回调即见顶 |
| 连板 / 妖股 | `CONSECUTIVE` | 前 1 或前 2 日存在涨停 | 资金分歧大、情绪波动极强 |
| ST 股涨停 | `ST_LIMIT` | 名称含 `ST` 且涨幅落在 4.8%~5.2% | 制度不同（5%），单独识别 |
| **通过全部门槛** | `QUALITY` | 满足 S1+S2+S3 且不命中上述任一否决项 | **唯一可作为战法标的的类型** |

**判定优先级**（命中即返回，自上而下）：
`ST_LIMIT` → `NONE` → `CONSECUTIVE` → `HIGH_POSITION` → `ONE_WORD` → `TAIL_SNEAK` → `WEAK_SEAL` → `QUALITY`

### 3.5 第 2 层：回调观察

- 回调窗口：涨停日之后 **3 ~ 15 个交易日**（少于 3 日洗盘不充分；超过 15 日视为形态失效）。
- 观察重点：量能节奏、支撑位是否失守、K 线形态、板块情绪。
- 原文：「涨停后的小幅回落，大多不是出货，是主力刻意洗盘」。

### 3.6 第 3 层：五大共振入场信号

原文：**「五个信号必须共振，才可以分批入场，少一个都坚决不动手。」** 且「五个信号全部共振，就是风险最低、收益最高的绝佳入场点」。

#### 信号一：回调持续缩量，量能逐日递减

| 项目 | 内容 |
|---|---|
| **原文** | 「这是判断『洗盘 vs 出货』的核心标准，也是最重要的信号。主力洗盘的特征：股价回落、但是资金不走、筹码锁仓。反映在盘面上就是：回调每一天的成交量，都比涨停当天小，而且一天比一天缩量。**口诀我记了九年：缩量回调是洗盘，放量回调是出货。**」 |
| **通过条件** | ① 回调期每一天成交量 < 涨停日成交量；② 量能呈逐日递减趋势 |
| **否决条件** | 回调过程中放出巨量、量能**超过涨停日** → 主力资金大幅出逃、筹码崩坏，后续大概率持续阴跌，坚决规避 |
| **逻辑** | 只有持续缩量才能证明场内资金惜售、没有抛压，随时会重启拉升 |
| **权重** | 25%（原文称为「最重要的信号」） |

#### 信号二：守住关键支撑，不破安全区间

| 项目 | 内容 |
|---|---|
| **原文** | 「我固定两个硬核支撑位，只要守住，机会就在：1、**第一道安全支撑：涨停实体K线的二分之一位置**，回调极限回踩不能跌破半分位，跌破说明主力控盘力度变弱，洗盘变弱势。2、**终极防守支撑：涨停当天开盘价**，这是主力成本底线，但凡真正想做二波行情的主力，绝对不会跌破自己的启动成本。只要回调始终运行在支撑位上方，不深跌、不破位，就是标准的良性洗盘形态。」 |
| **通过条件** | 回调全程运行在两道支撑位（半分位、涨停开盘价）上方；另以 MA5 / MA10 / MA20 作为动态支撑参考 |
| **否决条件** | **有效跌破涨停当日开盘价** → 形态彻底破坏，洗盘变出货 |
| **权重** | 25% |

#### 信号三：分时止跌企稳，低点逐步抬高

| 项目 | 内容 |
|---|---|
| **原文** | 「真正的企稳，**先看分时，再看K线**。洗盘末期，盘面会出现明显变化：日内不再创出新低，每次回落的低点越来越高，分时均价线稳稳托住股价，跳水力度越来越弱，承接越来越强。这种分时走势，说明空头动能彻底衰竭，抛压已经释放完毕，主力已经开始暗中护盘，距离重启拉升只差一根启动阳线。」 |
| **通过条件** | ① 回调后段日内不再创新低；② 每次回落的低点逐步抬高；③ 下跌斜率趋缓、承接趋强 |
| **数据限制** | 分时数据依赖逐笔/分钟级行情。本系统以**日线代理指标**实现：后段（最后 3 日）最低价不再创新低且逐步抬高、日内收盘位置 `(close − low) / (high − low)` 均值走强 |
| **权重** | 15% |

#### 信号四：K线筑底止跌，小阳十字星收尾

| 项目 | 内容 |
|---|---|
| **原文** | 「良性回调的末端，**绝对不会出现大阴线、破位阴线**。标准企稳形态：连续收出小阳线、十字星、小阴小阳交替，股价重心稳稳上移，整体横盘震荡，拒绝下跌。这代表多空彻底平衡，散户该割的已经割完，浮筹清洗干净，主力随时准备启动二波行情。**一旦回调末端出现大阴线砸盘，直接放弃观察，形态彻底破坏。**」 |
| **通过条件** | 末端出现小阳线 / 十字星 / 小阴小阳交替；实体幅度 `\|close − open\| / pre_close ≤ 1.5%`；股价重心横盘或上移 |
| **否决条件** | 末端出现大阴线（单日跌幅 `≤ −3%` 视为破位阴线） |
| **权重** | 20% |

#### 信号五：板块情绪同步回暖，题材有持续性

| 项目 | 内容 |
|---|---|
| **原文** | 「个股走势，永远脱离不了板块。脱离题材谈个股技术形态，都是纸上谈兵。我入场的最后一道关卡：个股所属当下主流热点主线，且板块经过短期回调后，出现止跌回暖、资金回流、赚钱效应回升。**个股强、板块弱，是独木难支，容易冲高回落；个股企稳、板块回暖，才是情绪共振，二波拉升成功率大幅拉满。**」 |
| **通过条件** | 所属行业/板块经短期回调后止跌回暖；资金回流；赚钱效应回升 |
| **量化方式** | 板块情绪分（0~100）由同行业成分股近 5 日平均涨幅、板块内涨停家数占比、上涨家数占比合成；同时校验个股与板块方向一致（拒绝「个股强、板块弱」） |
| **权重** | 15% |

### 3.7 第 4 层：买卖与风控计划

| 项目 | 规则 |
|---|---|
| **买入区间** | 以活跃支撑位（涨停开盘价 / MA5 / MA10 中最接近现价且不高于现价者）为下限，向上留缓冲；上限不超过涨停实体半分位与现价的较小值 |
| **止损** | **涨停当日开盘价**（主力成本底线）。原文：「一旦回调有效跌破涨停开盘价底线支撑，说明形态彻底破坏，洗盘变出货，果断离场，不幻想、不扛单。」工程实现取 `涨停开盘价 × 0.99` 作为触发线，避免盘中假跌破 |
| **止盈一** | 涨停日最高价（前高压力位） |
| **止盈二** | 涨停日最高价 × 1.10 |
| **盈亏比** | `(止盈一 − 买入中值) / (买入中值 − 止损)` |
| **仓位** | 原文「**分批入场，不重仓梭哈**」。按评分映射：`≥90 → 40%`、`≥85 → 30%`、`≥80 → 20%`、其余 `10%`；固定**分 3 批**建仓 |
| **风险等级** | 由评分、回调天数、距支撑位距离、量能形态综合判定为 `低 / 中 / 高`，并输出具体风险点 |

### 3.8 第 5 层：交易纪律（不可违背）

原文：「这套战法我能从 15 万做到 230 万，不是抓妖股、不是赌行情，而是靠**铁一般的纪律**。」

| 编号 | 纪律（原文） | 系统体现 |
|---|---|---|
| D1 | **绝不提前抄底**：回调没有缩量、没有企稳、没有筑底，坚决不提前潜伏。很多人做回调亏钱，就是耐不住寂寞 | 五信号未全通过时 `verdict ≠ BUY`，明确提示「等待」 |
| D2 | **只做低位首板回调，不碰高位票**：高位连板、暴涨过后的标的，一律不参与回调，规避主力高位出货风险 | `HIGH_POSITION` / `CONSECUTIVE` 直接否决 |
| D3 | **无信号坚决空仓**：没有共振信号就耐心空仓等待。炒股赚钱靠等待，不靠频繁操作，少做杂毛、只做精品 | 无标的时展示空仓提示，不推荐「勉强可买」标的 |
| D4 | **分批入场，不重仓梭哈**：分批低吸、滚动操作，既规避突发风险，又能拿到完整二波行情 | 输出 `positionPct` 与 `batchCount = 3` |
| D5 | **跌破支撑果断止损**：有效跌破涨停开盘价底线支撑，果断离场，不幻想、不扛单 | 输出 `stopLoss` 并在低吸池中跟踪跌破状态 |
| D6 | **拒绝情绪化交易**：重复做高胜率机会，实现长期复利 | 以评分与回测数据替代主观判断 |

### 3.9 避坑要点

| 坑 | 后果（原文） |
|---|---|
| 回调放量、量能超过涨停日 | 主力资金大幅出逃、筹码崩坏，后续大概率持续阴跌 |
| 回调末端大阴线砸盘 | 形态彻底破坏，多空未平衡，直接放弃观察 |
| 烂板 / 偷袭板 / 缩量板 / 高位板 | 回调大概率是下跌中继，坚决不能碰 |
| 个股强、板块弱 | 独木难支，容易冲高回落 |
| 盲目抄底（下跌途中） | 被持续磨盘洗出局 |

### 3.10 评分与结论模型

- 每个信号输出 `score`（0~100）、`passed`、`weight`；`contribution = score / 100 × weight × 100`。
- 总分 `score = Σ contribution`（0~100）。
- 结论 `verdict`：

| 结论 | 条件 | 中文 | 系统行为 |
|---|---|---|---|
| `BUY` | `score ≥ 75` **且五个信号全部 passed** | 可低吸 | 高亮推荐，提供完整交易计划 |
| `WATCH` | `score ≥ 55`，或信号四/五通过 | 观察 | 列入观察池，提示等待信号补齐 |
| `REJECT` | `score < 55`，或命中任一硬性否决 | 放弃 | 从推荐列表剔除，可查否决原因 |

**硬性否决清单**（任一命中即 `REJECT`，不受评分影响）：

1. 涨停类型非 `QUALITY`；
2. 回调放量、量能超过涨停日；
3. 回调有效跌破涨停日开盘价；
4. 回调末端出现大阴线砸盘；
5. 回调天数不在 `[3, 15]` 区间。

## 4. 用户与使用场景

### 4.1 用户画像

| 角色 | 特征 | 核心诉求 |
|---|---|---|
| **盘后选股者（主要）** | 有正职，每日收盘后花 20~30 分钟复盘 | 一键扫描出当日候选标的，直接看到评分与买卖计划 |
| **纪律执行者** | 曾因追高亏损，希望借助系统约束自己 | 无信号时明确空仓提示；破位自动标记止损 |
| **方法学习者** | 正在学习该战法，希望理解每个信号的判据 | 规则页完整呈现原始规则与量化阈值；个股页展示五信号明细 |
| **策略研究者** | 想验证该方法是否真的有效 | 回测页的胜率、盈亏比、最大回撤、分信号统计 |

### 4.2 典型使用流程

**场景 A：每日盘后选股（主线流程）**

1. 打开首页 → 查看市场情绪（冰点/偏冷/中性/偏暖/过热）与涨停家数；
2. 进入「信号选股」→ 点击「重新扫描」→ 等待进度完成；
3. 按评分降序查看候选 → 筛出 `verdict = 可低吸` 的标的；
4. 进入个股详情 → 核对五大信号明细、支撑位、买入区间、止损位；
5. 认可的标的「加入低吸池」→ 次日按分批计划执行；
6. 无符合标的时，系统提示「今日无共振信号，建议空仓等待」。

**场景 B：持仓跟踪**

1. 进入「自选低吸池」→ 查看每只标的的状态标签（观察中 / 已触发 / 已止盈 / 已止损）；
2. 现价跌破止损位 → 状态自动变为「已止损」→ 提示果断离场；
3. 现价进入买入区间 → 状态变为「已触发」。

**场景 C：方法验证**

1. 进入「回测分析」→ 调整回放窗口、最低评分、持有天数；
2. 查看胜率、平均收益、盈亏比、最大回撤、净值曲线、收益分布；
3. 查看分信号统计，判断哪个信号最具预测力。

## 7. 数据需求

### 7.1 数据项

| 数据 | 字段 | 用途 | 来源 |
|---|---|---|---|
| 股票基础信息 | 代码、名称、交易所、板块、行业、是否 ST、涨停幅度 | 展示、涨停判定、板块共振 | 数据源 |
| 日线行情 | 日期、开、高、低、收、前收、涨跌幅、成交量、成交额、换手率、量比 | 全部技术判据 | 数据源 |
| 均线 | MA5、MA10、MA20、MA60 | 动态支撑、趋势判断 | 服务端计算 |
| 板块行情 | 行业名称、板块涨跌幅、板块内涨停家数、成分股数、情绪分 | 信号五 | 服务端聚合 |
| 市场行情 | 涨停/跌停/炸板家数、涨跌家数、总成交额、平均涨跌幅 | 首页情绪 | 服务端聚合 |
| 用户数据 | 低吸池条目、策略参数 | 个性化 | 服务端持久化 |

### 7.2 数据窗口

| 用途 | 最少所需交易日 |
|---|---|
| 计算 MA60 | 60 |
| 计算 120 日位置（高位判定） | 120 |
| 回测（默认 120 日回放 + 5 日持有） | 125 |
| **合计建议** | **250**（预留缓冲，确保任何判据都不因数据不足而失真） |

### 7.3 数据源策略

采用**多源真实行情 + 按操作故障转移**设计（v1.1 起），三层保障：

| 层次 | 机制 | 说明 |
|---|---|---|
| 第一层 | **多真实源并行可用** | 东方财富、腾讯财经、新浪财经三个公开行情源，优先级由 `DATA_SOURCE_ORDER` 配置（默认 `eastmoney,tencent,ths,sina`） |
| 第二层 | **按操作故障转移 + 健康度退避** | 取列表/取日线/取实时行情各自独立切换；失败源进入指数退避冷却后被跳过，冷却结束自动恢复 |
| 第三层 | **合成数据兜底** | 仅当**全部**真实源不可用时启用，接口与界面均明确标注「演示数据」 |

**数据源模式**：

| 模式 | 行为 | 适用场景 |
|---|---|---|
| `auto`（默认） | 按优先级尝试真实源；全部失败才降级为合成数据 | 一般生产环境 |
| `real` | 同上但**绝不降级**，全部真实源失败即报错（HTTP 503） | 生产环境（及早暴露数据源故障） |
| `eastmoney` / `tencent` / `sina` | 强制只使用指定单一源 | 排查某个源的字段差异 |
| `synthetic` | 强制使用内置合成数据，完全离线 | 演示、内网、自动化测试 |

**各源能力与差异**（适配器内已归一化）：

| 源 | 全市场列表 | 日线 | 实时批量 | 备注 |
|---|---|---|---|---|
| 东方财富 | ✅ 字段最全（含成交额，便于按流动性排序） | ✅ 前复权 | ✅ | 部分网络环境会在 TLS 层阻断该域名，适配器做了**快速失败**（连接超时 ≤4 秒） |
| 腾讯财经 | ❌ 不提供全市场列表 | ✅ 前复权 | ✅ 支持批量 | 列表由其他源提供，日线用腾讯 —— 故障转移层自动组合 |
| 新浪财经 | ✅ 支持分页 | ✅ 不复权 | ✅ 支持批量 | 连续快速翻页会触发反爬（HTTP 456，封禁约 10 分钟），适配器已加翻页延时与限流重试 |

**实测记录**（本机网络环境，东方财富被阻断）：

```
ping eastmoney  -> False  (1.00s)          # TLS 层被阻断，快速失败
ping tencent    -> True   (0.81s)
ping sina       -> True   (0.61s)

股票列表: 1000 只  来源=sina   用时=44.70s   # 东方财富失败后自动切到新浪
日线 600519: 60 行  来源=tencent  用时=0.28s  # 列表用新浪、日线用腾讯，自动组合
批量日线: 200/200 只成功  用时=9.66s  平均 48ms/只
```

> 该记录同时验证了需求 3：东方财富不可用时，系统**没有**降级为演示数据，
> 而是自动切换到新浪取列表、腾讯取日线，全程无需人工干预。

**合成数据要求**（保证离线环境产品仍完整可用）：

1. 固定随机种子，结果**可复现**（实测：同种子两次生成，行情表逐行完全一致）；
2. 生成带真实感的行业化股票名称、6 位代码、行业分布、板块混合。
   **所有演示股票名统一追加「（演示）」后缀**，避免用户将其与真实上市公司代码混淆；
3. 约 250 个交易日日线，价格随机游走 + 行业联动因子，涨跌幅受 ±10% / ±20% 限制，
   并在生成末尾统一做一次涨跌停制度合法性收口（任何一天的涨跌幅都不越界）；
4. **刻意植入 64 只**「优质首板 + 缩量回调企稳」样本（需求下限 30 只，实测 64 只），
   使信号页有真实可展示结果；其中约半数额外附带一个**历史同形态区间**
   （涨停 → 回调 → 二波拉升 → 平滑衔接回当前区间），使回测能获得跨越多日的样本；
5. 同时植入反面样本（连板 6、一字板 6、高位板 6、炸板 6、尾盘偷袭板 5、
   放量回调 8、破位砸盘 5、ST 涨停 3）以及当日涨停 10 只、当日炸板 4 只，
   用于对照与市场情绪面板统计。

**实测基线**（`DATA_SOURCE_MODE=synthetic`，`UNIVERSE_SIZE=300`，供验收对照）：

| 指标 | 实测值 |
|---|---|
| 全市场扫描规模 | 300 只 × 250 个交易日 |
| 命中信号（含观察） | 70 只左右 |
| 其中「可低吸」（五信号全共振） | 63 只左右 |
| `/api/v1/signals` 默认查询耗时 | ~0.05 s（缓存命中） |
| `/api/v1/market/overview` 首次耗时 | ~0.7～1.3 s |
| `/api/v1/backtest` 耗时 | ~0.6 s |
| 默认回测样本量（120 日 / 评分≥75 / 持有 5 日） | 约 50 笔，覆盖 11～14 个交易日 |
| 默认回测胜率 / 盈亏比 | 约 42% / 约 3.4 |
| 后端单元 + 接口测试 | 42 项全部通过 |

> 回测数值由固定随机种子的合成数据产生，**仅用于验证系统链路与统计口径正确**，
> 不代表也不预测任何真实收益。

**缓存策略**：行情数据落本地文件缓存，默认 TTL 300 秒，降低外部接口调用频率。

### 7.4 数据合规

- 仅使用**公开行情接口**与本地合成数据，不涉及任何非公开数据或付费数据源转售。
- 不采集任何用户身份信息，无账号体系，用户数据仅存于本地数据卷。

## 8. 规则引擎详细规格

### 8.1 输入

- 股票基础信息 `StockMeta`
- 日线序列（≥ 120 根，建议 250 根）
- 策略参数 `RuleSet`（见 8.4）

### 8.2 处理流程

```
① 涨停识别
   按 limitPct（主板 10% / 创业科创 20% / ST 5%）判定，
   容差 0.2% 以规避浮点误差；要求 close == high 或涨幅 ≥ limitPct × 98% 视为封板

② 涨停质量分类
   按优先级输出 LimitUpType，非 QUALITY → 该涨停不进入回调分析

③ 选取最近的 QUALITY 涨停日
   计算回调天数；不在 [3, 15] → 否决

④ 计算回调期指标
   逐日量能、量能与涨停日量能之比、回调幅度、
   回撤比例（相对涨停实体）、最低价与各支撑位的关系、
   末端 K 线实体幅度与阴阳、日内收盘位置

⑤ 五大信号独立评分（各 0~100）并判定 passed

⑥ 硬性否决检查
   命中任一 → 直接 REJECT（不受评分影响）

⑦ 加权汇总总分，判定 verdict

⑧ 生成买卖与风控计划（支撑位、买入区间、止损、两档止盈、盈亏比、仓位、批次）

⑨ 生成风险评级与风险点、中文形态解读
```

| 尾盘偷袭判定涨幅 | 6% | — | 否 |
| 烂板判定回落幅度 | 3% | — | 否 |
| 破位阴线判定跌幅 | −3% | — | 否 |
| 小实体判定幅度 | 1.5% | — | 否 |

## 12. 边界、假设与风险

### 12.1 明确不做（Out of Scope）

| 项 | 说明 |
|---|---|
| 自动交易 / 下单 | 不接券商接口，不做任何自动化交易 |
| 用户账号体系 | 无注册登录，无多用户隔离 |
| 实时行情推送 | 采用轮询与按需拉取，不做 WebSocket 逐笔推送 |
| 分钟级/分时真实数据 | 信号三以日线代理实现（已在 3.6 说明） |
| 收益承诺 / 投资建议 | 工具性质，不构成建议 |
| 移动 App | 仅 Web，移动端浏览器可用 |

### 12.2 关键假设

| 编号 | 假设 | 影响 |
|---|---|---|
| A1 | 原文的定性描述可被合理的数值判据代理 | 是所有量化实现的前提；判据已在 8.3 全量公开且可配置 |
| A2 | 涨停板制度为：主板 10%、创业板/科创板 20%、ST 5% | 若制度变化需调整 `limitPct` |
| A3 | 使用前复权日线数据 | 影响均线与位置比例计算 |
| A4 | 分时数据不可得时，信号三使用日线代理 | 会降低信号三的精度，已在文档披露 |
| A5 | 部署环境可访问公网行情接口，或接受合成数据 | 离线环境下产品功能完整但数据为演示性质 |

### 12.3 风险与应对

| 风险 | 等级 | 应对 |
|---|---|---|
| 外部行情接口变更或限流 | 中 | 三层降级（eastmoney → cache → synthetic），接口永不 5xx |
| 日线代理无法完全等价真实分时 | 中 | 在 UI 与文档中如实标注；权重设为最低的 15% |
| 回测存在过拟合与幸存者偏差 | 中 | 回测页显著标注局限性；不提供参数自动寻优 |
| 用户误将工具输出当作投资建议 | 高 | 全局免责声明、演示数据醒目标识、无信号时明确空仓提示 |
| 阈值参数化被用户调成极端值 | 低 | 权重合计必须为 1 才可保存；提供一键恢复默认 |
| 服务器资源不足导致构建失败 | 低 | 镜像多阶段构建 + 支持本地构建后导出部署 |

## 14. 附录：术语表

| 术语 | 含义 |
|---|---|
| **涨停** | 当日涨幅达到该板块涨跌停限制（主板 10%、创业板/科创板 20%、ST 5%） |
| **首板** | 近期第一个涨停（前 1~2 个交易日无涨停） |
| **连板** | 连续两个及以上交易日涨停 |
| **一字板** | 开盘即涨停且全天未打开，K 线呈「一」字形（`open = high = low = close`） |
| **实体涨停** | 开盘后有充分换手、盘中拉升封板的涨停形态 |
| **烂板 / 炸板** | 盘中触及涨停但未能封住，收盘明显回落 |
| **尾盘偷袭板** | 全天走势平淡，尾盘最后几分钟急速拉升封板 |
| **高位板** | 涨停日收盘价处于近 120 日区间的高位（位置比例 > 80%） |
| **缩量** | 成交量低于参考周期（此处为涨停日或前一交易日） |
| **放量** | 成交量显著高于参考周期 |
| **量比** | 当日成交量 / 前 5 日平均成交量 |
| **换手率** | 当日成交股数 / 流通股数 |
| **回调** | 涨停后股价的阶段性回落整理 |
| **洗盘** | 主力刻意打压股价以清洗浮筹的行为（缩量特征） |
| **出货** | 主力派发筹码的行为（放量特征） |
| **半分位** | 涨停实体K线的二分之一位置 `(开盘价 + 收盘价) / 2` |
| **主力成本底线** | 涨停当日的开盘价（原文视为主力启动成本） |
| **二波** | 回调结束后的第二段主升行情 |
| **浮筹** | 持股心态不稳、易被洗出的散户筹码 |
| **多空平衡** | 卖方抛压释放完毕、买卖力量均衡的横盘状态 |
| **共振** | 多个独立信号同时成立 |
| **盈亏比** | 预期盈利空间 / 预期亏损空间 |
| **最大回撤** | 净值从高点到低点的最大跌幅 |
| **炸板率** | 炸板家数 / （涨停家数 + 炸板家数） |
