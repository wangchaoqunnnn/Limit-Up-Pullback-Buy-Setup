# =============================================================================
# 运行期依赖（Python 3.12）
#
# 设计原则：
# 1) **固定版本**：避免不同时间/不同机器构建时装到不同版本导致行为漂移
#    （曾经因为只用 >= 下限，服务器构建结果与本地不一致）。
# 2) **二进制优先**：这些版本在 PyPI 上都有 Python 3.12 的 manylinux wheel，
#    正常情况下无需编译；Dockerfile 同时装了编译工具作为兜底。
# 3) **不含测试依赖**：pytest / respx 等只在开发与 CI 需要，见 requirements-dev.txt，
#    避免把它们打进生产镜像（更小、更少攻击面、更少可能失败的下载）。
# 4) 刻意不引入 akshare（体积大且接口易碎），真实数据源直接走各行情站公开 HTTP 接口。
# =============================================================================
